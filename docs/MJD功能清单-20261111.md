# MJD 本轮功能清单 · 2026-11-11

| 模块 | 原型实现 | 验收点 |
| --- | --- | --- |
| 场次码与准入 | 每场二维码与场次码；每人专属六位数字码；线下取消名单认领；首次配置线下默认盲测 | 错码、移除人员不能进入；正确码定位本人；线上原流程保留 |
| 声纹 | 主持人在配置名单或会议信息发起、停止、重录、保存；Pad 同步朗读文案与状态 | 未保存不通过；重录时重新进入朗读页面；只保存对应人员 |
| 题目控制 | 开始题目与投放大屏分开；仅标注题额外有投放前题答案 | 大屏仅呈现题目和结果；前题投放不改变当前作答题；浏览历史不自动开始 |
| AI 提示 | 右侧为短标签；中间保留完整话题追问；累计超时显示暖色提示 | 不自动切题；本地覆盖／含糊规则只是展示演示，不代表跑题和矛盾的模型判断能力 |
| 旁听沟通 | 问 AI 与递小纸条独立；AI 按本场发言摘取并附题号；信封未读数、阅读后灰色置底 | 问 AI 不进入主持信箱；未读和阅读状态跨同浏览器窗口同步；不再显示置顶操作 |
| 会议信息 | 场次名称、方式、测试方式、场次码、受访者二维码／链接、旁听室链接、状态；展开逐人数字码／声纹 | 个人码逐人复制；菜单可滚动，窄屏不溢出 |

已确认：盲测默认设置在新建线下场次配置中，受访者沿用，不再选择。

仍为前端原型。扫码链接、个人码、音频、AI 和多端协作需要正式服务端落地；当前仅同一浏览器窗口之间联动。
