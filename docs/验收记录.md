## 实际浏览器走查

- Mizzen 工作空间 → 焦点小组 → 研究项目 → 新建场次 → 配置页 → 主持台。
- 输入研究目标 → 生成可编辑大纲 → 修改研究名称与访谈指引 → 发布 → 可新建场次。
- 同一配置页线上／线下切换保留名称、名单与已填信息；受访者链接、独立旁听链接可新窗口打开。
- 受访者房间码 → 名单选择 → 知情同意 → 等待 → 主持人开始题目；访谈回答与单选提交同步至主持台和旁听室。
- 旁听发送小纸条，主持人顶栏信箱标记已处理，旁听端回传状态；草稿在热更新及结束态继续保留。
- 前题投放在受访者端同时呈现前题全员汇总与当前题结果。
- 受访者拖动圈选蓝色区域并提交，主持台单张汇总图保留该实际标记；材料可放大。
- 线上结束后，受访者显示感谢页，旁听室进入只读复盘并禁用发送。
- 线下配置启用主持人与受访者声纹后进入主持台；线下旁听无会议信息、无受访者视图，保留题目与现场全景放大。
- CSV 名单导入显示真实文件的预览，确认后新增到现有名单；手动添加输入身份与背景后可保存，名单即时更新。
- 1280×720 旁听布局无横向溢出，发送按钮底部为 711px。
