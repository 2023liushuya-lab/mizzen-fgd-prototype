# 本地迁移验收 · 2026-11-09

本记录只验证交互原型与本地前端工程，不代表正式音视频、AI 或后台权限已接入。

## 实际浏览器走查

- Mizzen 工作空间 → 焦点小组 → 研究项目 → 新建场次 → 配置页 → 主持台。
- 输入研究目标 → 生成可编辑大纲 → 修改研究名称与访谈指引 → 发布 → 可新建场次。
- 同一配置页线上／线下切换保留名称、名单与已填信息；受访者链接、独立旁听链接可新窗口打开。
- 受访者房间码 → 名单选择 → 知情同意 → 等待 → 主持人开始题目；访谈回答与单选提交同步至主持台和旁听室。
- 旁听发送小纸条，主持人顶栏信箱标记已处理，旁听端回传状态；草稿在热更新及结束态继续保留。
- 前题投放在受访者端同时呈现前题全员汇总与当前题结果。
- 受访者拖动圈选蓝色区域并提交，主持台单张汇总图保留该实际标记；材料可放大。
- 线上结束后，受访者显示感谢页，旁听室进入只读复盘并禁用发送。
- 线下配置启用主持人与受访者声纹后进入主持台；线下旁听无会议信息、无受访者视图，保留题目与现场全景放大。
- CSV 名单导入显示真实文件的预览，确认后新增到现有名单；手动添加输入身份与背景后可保存，名单即时更新。
- 1280×720 旁听布局无横向溢出，发送按钮底部为 711px。

## 快速迭代验证

临时修改全局样式自定义属性，开发服务器生成新的 CSS；前台浏览器自动应用，随后恢复原样式，无需重新执行构建。实际回答、已处理纸条与输入框草稿均保留。验证用属性已经移除。

页面 DOM 没有旧 HTML 镜像 iframe。主持人与旁听直接复用 `QuestionWorkspace`；受访者投放直接复用不含 AI 的 `AnswerResults`。字体文件独立存放。

- 1280×720 主持台：顶栏 48px、底栏 58px，三栏为 272 / 704 / 304px，页面无横向溢出；中间内容最大宽度 1120px。
- 题目视图右侧恢复发言占比与独立话题追问卡片，视频集中到视频视图；聊天在左、会控居中、字幕在右。
- 受访者房间码、认领、同意、设备检测、入场链路可走通；设备检测真实权限只在点击检测时申请，本轮未开启实际摄像头或麦克风。

- 受访者未提交草稿刷新后保留，右侧恢复单个视频预览和紧凑人员列表。
- 新建场次采用原版四章节默认结构；已有场次快照与历史章节时间不回写。
- TypeScript、24 项行为测试与 Next.js 正式构建均通过。

## 旁听室与主持台交互及视觉同步更新

- **旁听室入口与直接进场**：旁听链接归口至主持台顶部「会议信息」下拉面板中（支持一键复制与新窗口打开）；旁听者打开链接直接进入完整三栏工作台，移除进入前昵称门禁与待开场遮挡页，待开场及会中均可自由浏览大纲全部题目。
- **递小纸条与话题追问融合**：线上与线下旁听室右侧移除分 Tab，统一为 `发言占比` + `话题追问` + 整体式 `递小纸条` 卡片（去除署名栏与关联题目下拉框）；主持人端移除右上角独立小纸条抽屉，将收到的旁听小纸条直接展示在「发言占比」下方的「话题追问」卡片中，以暖琥珀色底色与 `旁听小纸条` 徽章同 `✧ AI` 追问清晰区分。
- **视频视图 / 现场画面精简**：移除旁听端声音开关按钮、视频视图下方的受访者回答记录列表及全屏/静音控件；线下「现场画面」隐藏受访者姓名与资料，线下模式隐藏底部栏左右切题按钮。
- **视觉语言与主持人端完全对齐**：底部受访者栏统一为 `在场 N 人` + 暖白金边圆形头像（悬停在上方弹出含座位号、状态、标签与字段网格的资料卡）；「发言占比」统一为暖米色渐变卡片、`360×360` 环形虚线座位饼图、四角人形剪影座位（带首字角标）及正下方主持人话筒位。

本轮未声称逐像素一致，真实 WebRTC、AI 生成与服务端权限仍属于后续接入范围。
